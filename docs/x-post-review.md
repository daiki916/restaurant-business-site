## 2. 検証結果

手法の骨格は**「商標キーワードでGoogle広告を出し、1枚の紹介ページ経由でアフィリエイトリンクに送る」**。
これは実在する手法だが、**投稿が明示している通りに実行すると、Google広告とASP規約の両方に構造的に衝突する。**

### 🔴 衝突1：「紹介ページを1枚作る」＝ Google広告のブリッジページ規定違反

Google広告の[遷移先ページの要件](https://support.google.com/adspolicy/answer/6368661?hl=en)および[Insufficient original content](https://support.google.com/adspolicy/answer/16427718?hl=en)ポリシーは、
**「他サイトへリンクするためだけに存在する中間ページ（bridge pages, doorways, gateways）」を明確に禁止**している。

固定ポスト②の「商品紹介ページを1枚作る」→③「そこに広告を出す」は、この定義にそのまま該当する。

- 制裁は掲載拒否（不承認）から**アカウント停止**まで。
- 停止の**7日前に警告**が出る運用だが、一度停止されると**新規アカウントを作っても自動停止**されるケースが報告されている。
- 回避策は「ページを増やす」ことではなく、**独自レビュー・比較表・長所短所・料金の文脈・診断ツールなど、そのページ自体に固有の価値を持たせること**。

### 🔴 衝突2：「商品名＋口コミ」＝ A8.net の禁止キーワード（NGキーワード）

A8.net は[禁止キーワード](https://support.a8.net/a8/as/faq/2014/05/post_172.html)制度を持ち、**商標名・会社名・サービス名およびその関連キーワードでの入札を禁止**している。

さらに違反の範囲が広い：

- ひらがな／カタカナ／ローマ字の表記ゆれ
- 打ち間違いキーワード
- **複数キーワードの組み合わせ**（＝「商品名＋口コミ」がまさにこれ）
- 商標を含むドメインでの掲載も商標権侵害の恐れあり

違反した場合の帰結は、[A8.netでの禁止事項](https://www.a8.net/compliance/prohibited-matter.php)および[リスティング広告ガイド](https://www.a8.net/compliance/listing.php)の通り**成果却下（＝広告費だけ払って報酬ゼロ）・提携解除**。

固定ポストは「広告掲載が認められているアフィ案件の中から」と一応の留保を置いているが、
**③で指定している出稿キーワードの型そのものが、禁止キーワードの典型例**になっている。この2つは両立しない。

**そして提示された10案件は、この点でとりわけ不向き。** 全案件が強いブランド商標を持つ：

| 案件 | 商標保有 | 商標KWリスティングの現実性 |
|---|---|---|
| タウンワーク | リクルート | 極低 |
| マッハバイト | リブセンス | 極低 |
| モッピー | セレス | 低 |
| 進研ゼミ | ベネッセ | 極低 |
| Lemino | NTTドコモ | 極低 |
| カシーボ | — | 要確認 |

自社ブランド名の検索結果を自社で獲れている大手広告主が、アフィリエイターに商標入札を許可する動機はほぼない。

### 🔴 衝突3：高単価3案件はGoogle広告に「認定」が必要

投稿の「◎1,000円〜：単価が高くて大きく稼げる」5案件のうち**3件がマッチング／出会い系**：

- **Jメール**（1,800円）
- **マリッシュ**（2,000円〜）
- **with**（2,200円〜）

Google広告の[マッチングとコンパニオン サービス](https://support.google.com/adspolicy/answer/15328393?hl=ja)ポリシーにより、
これらは**Googleの事前認定を取得した広告主のみ出稿可能**（2025年3月までに認定義務化）。年齢確認等の要件も伴う。

つまり**「単価が高くて大きく稼げる」と紹介されている枠の主力が、認定なしではそもそも出稿できない。**
残る高単価案件は進研ゼミ（ベネッセ商標）とLemino（ドコモ商標）で、こちらは衝突2に当たる。

### 🟡 衝突4：ステマ規制（2023年10月施行）への言及がゼロ

改正景品表示法の指定告示により、アフィリエイト広告には**「広告」「PR」等を一般消費者が認識できる位置に明瞭表示する義務**がある（[A8スタッフブログ](https://a8pr.jp/2023/08/31/fairlabeling/)、[楽天アフィリエイトの対応](https://affiliate.rakuten.co.jp/guideline/stealth_marketing_regulation/)）。

「AIに売れる型を読み込ませて作ればOK」の工程には、この表記も、根拠のない効果表現を避ける配慮も含まれていない。
**AI生成の「口コミ」を実体験のように書けば、それ自体がステマ規制・優良誤認の対象になる。**

### 🟡 会計上の問題：「無料」ではない

- 「A8（**無料の**アフィサイト）を登録するだけ」は事実だが、手法の本体はGoogle広告＝**先に広告費を払う**モデル。ASPの報酬支払いは月末締めの翌々月払いが一般的で、**広告費が先出し・報酬が後入り**のキャッシュフローになる。
- 「1日25分」（親ポスト）と「1日30分」（スレッド）が不一致。加えて、④「利益が出た案件を4〜5個」に至るまでの**検証期間の赤字**には触れていない。

### 🔴 単価の壁：250円案件で月10万円は成果400件

これが最も重要な算数。**報酬単価が低い案件では、CPCが1円でも成立しにくい。**

月10万円に必要な成果数：

| 単価 | 必要成果数／月 | 必要成果数／日 |
|---|---|---|
| 200円（カシーボ） | **500件** | 約17件 |
| 250円（タウンワーク） | **400件** | 約13件 |
| 300円（モッピー等） | **334件** | 約11件 |
| 1,200円（Lemino） | 84件 | 約3件 |
| 2,200円（with） | 46件 | 約1.5件 |

**これは粗利ゼロ（広告費を無視した）場合の数字。** 実際は広告費を差し引くので、必要成果数はさらに増える。
損益分岐は次の2式で決まる：

```
損益分岐CPC  = 報酬単価 × CVR
損益分岐CVR  = CPC ÷ 報酬単価
1クリックあたり損益 = (報酬単価 × CVR) − CPC
```

250円案件で総合CVR 5%なら、1クリックの価値は **12.5円**。
CPCが12.5円を超えた瞬間に、クリックするたび赤字が増える。
`tools/affiliate-breakeven.html`（本ブランチに同梱）で、10案件すべての損益分岐を自分の数字で確認できる。

## 3. 総合判定

| 論点 | 判定 |
|---|---|
| リスティングアフィリエイト自体は実在する手法か | ✅ 実在する。合法 |
| 「A8登録は無料」 | ✅ 事実 |
| 「SNSアカウント不要」 | ✅ 事実 |
| 「1枚の紹介ページ＋Google広告」 | ❌ ブリッジページ規定違反。アカウント停止リスク |
| 「商品名＋口コミ」で出稿 | ❌ A8禁止キーワード。成果却下・提携解除 |
| 提示された高単価3案件 | ❌ Google認定が必要（未取得では出稿不可） |
| 提示された低単価4案件 | ⚠️ 単価200〜300円では損益分岐CPCが極小 |
| 「1日25分／30分で月10万」 | ❌ 検証期間の赤字とキャッシュフローを無視 |
| ステマ規制対応 | ❌ 言及なし。実行すれば違反リスク |

**結論：手法のカテゴリは本物だが、投稿に書かれた手順のまま実行すると、
「Google広告アカウント停止」「ASP提携解除・成果却下」「ステマ規制違反」の3つを同時に踏みに行く構成になっている。**

「なんでみんなやらないんだろう？」の答えは、**多くの人がやって上記で焼かれたから**。
リスティングアフィリエイトが2000年代後半に流行し、その後Googleがブリッジページ規制を強化し、
ASPが商標入札を締めた、という歴史的経緯がそのまま反映されている。

なお、この投稿は「必要な手順は僕の"固定ポスト"で読めます」→固定ポストは「収益化4STEP」の概要のみ、という
**情報商材・有料コミュニティへの典型的な導線構造**になっている点も踏まえて判断されたい。
