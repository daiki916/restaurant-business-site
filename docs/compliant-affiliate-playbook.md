# リスティングアフィリエイトを規約適合で回す手順書

`docs/x-post-review.md` で指摘した4つの衝突を回避した版。
元投稿との差分は「何をやらないか」に集約される。

---

## 0. 前提：この手法の適性判断

先に降りる判断をしたほうが良いケース：

- **広告検証予算が10万円未満** → クリック単価と実CVRが分かるまでに使い切る。降りる。
- **Google広告アカウントを過去に停止されている** → 新規作成しても自動停止の対象になりやすい。降りる。
- **成果単価500円未満の案件しか扱えない** → 損益分岐CPCが数円〜十数円になる。降りる。
- **月内に現金が必要** → ASP報酬は月末締めの翌々月払いが一般的。広告費が先に出て報酬が後から入る。降りる。

上記に当てはまらない場合のみ、以下に進む。

## 1. 案件選定：「リスティング可」から逆に探す

元投稿は「アプリ」で検索して単価順に選んでいる。**順序が逆。**
リスティング可否は後付けで確認できる条件ではなく、**この手法が成立するかどうかを決める唯一の前提条件**。

### 手順

1. A8.net 管理画面のプログラム検索で、**「リスティング広告」の可否を先に絞る**
   - プログラム詳細の「広告主からのメッセージ」「提携条件」「NGキーワード」欄を必ず開く
   - [リスティング広告ガイド](https://www.a8.net/compliance/listing.php) と [禁止キーワードとは](https://support.a8.net/a8/as/faq/2014/05/post_172.html) を先に読む
2. 次の記載があれば**即除外**
   - 「リスティング広告禁止」「商標キーワード出稿禁止」「指名検索での出稿禁止」
   - NGキーワード欄に商標名・サービス名が列挙されている（＝ほぼ全案件）
3. 残った案件のうち、**成果単価1,000円以上**のものだけを候補にする
4. 候補が0件なら、**この手法は今のあなたには成立しない。** 案件が出るまで待つか、別の集客手段（SEO・SNS）に切り替える

### 判断に迷ったら広告主に直接確認する

A8の管理画面から広告主へメッセージを送り、**書面で許諾を取る**。
「リスティング可」と書いてあっても、商標KWは別扱いのことが多い。確認する文面の型：

> 貴プログラムにてリスティング広告（Google 検索広告）での集客を検討しております。
> 下記について可否をご教示いただけますでしょうか。
> ① 一般キーワード（例：「〇〇 アプリ おすすめ」）での出稿
> ② 商標・サービス名を含むキーワードでの出稿
> ③ 商標を含まない独自ドメインの比較・レビューページを遷移先とすること

**この返信を保存しておく。** 成果却下の異議申立てで唯一効く証拠になる。

## 2. キーワード：商標を捨てて「比較・代替」に寄せる

元投稿の「商品名＋口コミ」「商品名＋最安値」は**使わない。**

代わりに狙う型（すべて商標を含まない）:

| 型 | 例 |
|---|---|
| カテゴリ＋おすすめ | `バイト探し アプリ おすすめ` |
| 課題＋解決 | `単発バイト 即日 探し方` |
| 属性＋比較 | `40代 マッチングアプリ 比較` |
| 条件＋一覧 | `ポイ活 サイト 安全 一覧` |

**必ず設定する除外キーワード**（Google広告のキャンペーン単位で）:

- 提携中の全案件の商標名 — **ひらがな・カタカナ・ローマ字・打ち間違いの全表記ゆれを含む**
- 競合の商標名
- `無料` `やり方` `退会` `解約` `評判 悪い` — 成果につながらないクエリ

除外キーワードは「念のため」ではなく**A8の違反判定を回避する必須作業**。
部分一致マッチで商標クエリを拾った時点で違反になり得る。フレーズ一致・完全一致から始めるのが安全。

## 3. 遷移先ページ：ブリッジページにしない

Google の [Insufficient original content](https://support.google.com/adspolicy/answer/16427718?hl=en) を通すために、
**1枚のLPではなく、それ自体で完結する情報資産を作る。**

### 最低要件（すべて満たすこと）

- [ ] **複数サービスの比較表** — 単一案件への一方通行はブリッジページ判定を受ける。提携していないサービスも含めて並べる
- [ ] **一次情報** — 実際に自分で登録し、スクリーンショットを撮る。AI生成の「口コミ」は使わない
- [ ] **短所の記載** — 長所だけのページは価値がないと判定される。かつ優良誤認の予防になる
- [ ] **料金・条件の文脈** — 「無料」の範囲、有料への切替条件、解約方法
- [ ] **運営者情報ページ** — 氏名または屋号、連絡先。実在性の証明
- [ ] **プライバシーポリシー** — Cookie・アクセス解析の利用を記載
- [ ] **サイト内の他ページ** — トップ・カテゴリ一覧・関連記事。単一ページのドメインは不審判定を受けやすい
- [ ] **商標を含まないドメイン** — 商標入りドメインは商標権侵害で提携解除の対象

### ステマ規制対応（必須・省略不可）

改正景品表示法により、以下を満たす必要がある（[A8の告知](https://a8pr.jp/2023/08/31/fairlabeling/)）:

- [ ] **ページ最上部**に「広告」「PR」「アフィリエイト広告を含みます」を明示
  - 本文末尾・折りたたみ内・薄いグレー文字は**不可**（「一般消費者が認識できる位置にわかりやすく」の要件を満たさない）
- [ ] 各アフィリエイトリンクの近傍にも表記
- [ ] 実体験でないものを実体験として書かない
- [ ] 根拠のない優位性表現（「No.1」「最安」「必ず」）を使わない — 根拠を示せない限り優良誤認

## 4. 広告運用：損益分岐から逆算する

`tools/affiliate-breakeven.html` を開いて、**出稿前に**次を確定させる。

```
損益分岐CPC = 報酬単価 × 総合CVR
損益分岐CVR = CPC ÷ 報酬単価
```

**総合CVR**＝広告クリックから承認成果までの通し率。ここを楽観視すると必ず赤字になる。
未検証段階では **2%** で置く（クリック50回で成果1件）。実測が出たら差し替える。

### 出稿設定

| 項目 | 推奨 | 理由 |
|---|---|---|
| マッチタイプ | フレーズ一致・完全一致のみ | 部分一致は商標クエリを拾い、A8違反になる |
| 入札戦略 | 個別クリック単価（上限＝損益分岐CPCの70%） | 自動入札は学習期間に損益分岐CPCを超える |
| 日予算 | 損益分岐CPC × 30クリック程度 | 1日で判断できず、かつ致命傷にならない額 |
| 検索パートナー | オフ | 品質が読めない |
| ディスプレイ拡張 | オフ | 「今すぐ欲しい層」ではない |
| コンバージョン計測 | ASPの成果地点と突合 | 広告側の数字だけでは承認率が分からない |

### 撤退ライン（出稿前に決めて書き留める）

- 累計200クリックで成果0件 → そのキーワード群を停止
- 実測CPAが報酬単価を上回った状態が3日続く → 停止
- **承認率**が判明した時点で全計算をやり直す（アプリDL案件は非承認・重複判定が出る）

## 5. 拡張

元投稿④「利益が出た案件を4〜5個」に相当する工程。ただし前提が違う。

**1案件が黒字化して、承認率まで確認できてから**次に進む。
複数案件を同時に走らせると、赤字の原因がキーワードか、ページか、案件かの切り分けができない。

## この手順書の工数見積り

| 工程 | 実工数 |
|---|---|
| 案件選定＋広告主への可否確認（返信待ち含む） | 3〜10日 |
| 比較ページ作成（実際に登録・スクショ撮影含む） | 10〜20時間 |
| 運営者情報・プライバシーポリシー整備 | 2〜3時間 |
| Google広告アカウント作成・審査通過 | 1〜7日 |
| 検証出稿（黒字化判断まで） | 2〜6週間・予算5〜15万円 |

**「1日25分」になるのは、黒字の型が1つ確立した後の運用フェーズだけ。**
元投稿はこの運用フェーズの工数を、立ち上げ工数として提示している。
