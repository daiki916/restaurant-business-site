# neon-loop

写真1枚から、SNSで自動ループ再生される正方形の短尺アート動画を生成するツール。

黒背景に浮かぶ被写体を、ネオン色の縦ストリーク（ピクセルストレッチ）で
絵の具が滴り落ちるように加工し、始点と終点が繋がる 24 フレームのループにする。

## セットアップ

```bash
pip install numpy pillow imageio-ffmpeg
```

ffmpeg は `imageio-ffmpeg` に同梱のものを自動で使うので、別途インストールは不要。

## 使い方

```bash
# デモ画像を自動生成して出力（動作確認用）
python3 neonloop.py -o demo.mp4

# 手持ちの写真から生成
python3 neonloop.py photo.jpg -o out.mp4

# GIF も一緒に出す
python3 neonloop.py photo.jpg -o out.mp4 --gif
```

出力はデフォルトで 1280×1280 / 24 フレーム / 33.33fps（＝約 0.72 秒）。

## 主なオプション

| オプション | 既定値 | 効果 |
|---|---|---|
| `--size` | 1280 | 出力解像度（正方形） |
| `--frames` | 24 | フレーム数。増やすと動きがゆっくりになる |
| `--fps` | 33.33 | フレームレート |
| `--stretch` | 0.55 | streak の最大長。上げると滴りが長く伸びる |
| `--strength` | 0.92 | streak の濃さ。下げると元画像が透ける |
| `--jitter` | 0.05 | 滴りの立ち上がりのギザギザ具合 |
| `--sat` | 1.9 | 彩度。ネオン感の強さ |
| `--glow` | 0.55 | 発光の強さ |
| `--grain` | 7.0 | フィルムグレインの粒立ち |
| `--bob` | 0.004 | 被写体の上下の揺れ幅 |
| `--seed` | 7 | 乱数シード。変えると streak の散り方が変わる |

## 元画像を選ぶコツ

このエフェクトは **明るさが急に立ち上がる行** を起点に色を引き伸ばす。そのため、

- **背景が暗く、被写体だけが明るい** 写真が一番きれいに決まる
- 被写体の輪郭がはっきりしているほど、滴りの起点が揃って美しくなる
- 全面が均一に明るい写真（日中の屋外など）は起点が定まらず、効果が出にくい

夜の店内、間接照明、逆光のシルエットなどが向いている。

## 処理の中身

1. 正方形にトリミング
2. 列ごとに「明るさが立ち上がる行」を検出し、そこを起点に色を下方向へ減衰させながら引き伸ばす
3. 彩度を上げ、マゼンタ／ブルー寄りに色を振る
4. 明るい部分だけをぼかしてスクリーン合成し、発光感を出す
5. 毎フレーム更新されるグレイン＋縦スクラッチノイズを乗せる
6. 上下の揺れと streak の伸縮を `sin` で駆動するため、最終フレームが先頭フレームに繋がる
