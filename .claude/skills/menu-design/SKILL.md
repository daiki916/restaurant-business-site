# 飲食店デザインスキル

日本の飲食店販促デザイン(Pinterestで流通している商用実例の分析)から抽出した制作規則。
**このスキルの核心: プロはゼロから発明しない。型を選び、型を崩さず実行する。**

## 手順

1. 依頼から **業態・品数・価格帯・用途** を読み取る
2. 下の表で **型を1つ選ぶ**(迷ったら複数案ではなく、根拠を添えて1案に絞る)
3. `references/patterns.md` の該当する型の節を読み、レイアウト規則に従って設計する
4. `references/pipeline.md` の手順でHTML/CSSアートボードを組み、PNGに書き出す
5. 出荷前に本ファイル末尾の **チェックリスト** で自己検品する

## 型の選択

| 型 | 使う場面 | 例 |
|---|---|---|
| **A. 写真ドン!型** | 看板商品1品を売る。ポスター・SNS告知・季節限定品 | 黒地に金、割ったカレーパンの断面、「かりっごろっ」 |
| **B. 対決・分割型** | 2枚看板の比較。キャンペーン。迷わせて選ばせる | 「甘辛vs旨辛どっち派?」赤黒2分割の丼ポスター |
| **C. 整列カタログ型** | 品数が多いメニュー本体。ランチ表。定食屋・中華・居酒屋のフードメニュー | グリッドに写真+品名+価格を反復 |
| **D. 余白・編集型** | 高級店・自然派・カフェ。ブランドを売る。コース表 | 白ベースに細い文字、雑誌の誌面のような構え |

業態が和(居酒屋・和食・寿司)なら、どの型でも **縦書き**(`writing-mode: vertical-rl`)の見出しを第一候補にする。縦書きは和の記号として機能が強い。

## 絶対規則(全型共通)

これを破った紙面は素人に見える。理由も含めて内面化すること。

- **色は3色+アクセント1色まで。** 色数が増えるほど安く見える。迷ったら減らす。
  - 業態別の定石: 焼肉・ラーメン=黒×赤×金 / 和=紺×朱×生成り / カフェ=クラフト茶×生成り×白 / 高級=生成り×金×墨 / ヘルシー=緑×白×墨
- **フォントは2種まで。** 見出し=明朝(Noto Serif JP)、本文・価格=ゴシック(Noto Sans JP)が基本形。モダン業態は見出しもゴシック太字でよい。3種目を足したくなったらウェイト差で解決する。
- **文字サイズの落差は3倍以上。** 「見出し:本文=3:1」が最低ライン。素人の紙面は1.5:1で平板になる。読ませる順番(視線の入口→興味→詳細)をサイズで設計する。
- **価格は数字だけ太く大きく、¥・税込・円は小さく。** 数字が商品情報の本体。`font-feature-settings: "palt"` で和文の字間を詰め、見出しには `letter-spacing: 0.1〜0.3em` を与える。
- **料理(写真・モチーフ)は暗い背景に置くと照りが出て高く見える。** 明るい背景は「気軽・健康・カフェ」の記号。価格帯と一致させる。
- **事務情報(店名・電話・営業時間・住所)は最下部に1列、装飾なしで整列。** デザインと情報を混ぜない。
- **質感語(シズルワード)を1つ添える。** 「かりっ」「とろり」「炭火の香ばしさ」— 写真やモチーフの弱さを言葉が補う。多用は禁物、1紙面に1つ。

## 制作パイプラインの選択

**実写の質感が品質を決める案件(ポスター・SNS告知・看板商品訴求)では、Canvaハイブリッドを第一候補にする。**
CSS/SVGだけの紙面は構成が正しくても「写真の力」で商用実例に負ける(実測済み)。

### パイプラインα: Canvaハイブリッド(写真が必要なとき)

Canva MCPが接続されている場合の手順。Canvaが写真・素材、このスキルがタイポグラフィの規律を担当する:

1. `generate-design` に詳細な日本語クエリ(業態・掲載文言・配色・「実写写真」指定)を渡す
2. 候補から1案を `create-design-from-candidate` でデザイン化
3. `read-design`(open_transaction: true)で全要素の locator_id・座標・フォントサイズを取得
4. **Canva生成物の典型的弱点をこのスキルの規則で矯正する**(ここが価値の中心):
   - 見出しが小さく平板 → 本文の3倍以上に拡大・太字化(要 resize_element で幅も拡大)
   - 価格が地の文に埋没 → 数字だけ太字・大サイズ・金色等のアクセント色に
   - 階層の乱れ(補足情報が見出し級のサイズ) → 3読設計(0.5秒/3秒/10秒)に並べ直す
   - 事務情報の散乱 → 最下部に整列
5. 編集のたびに返却サムネイルで**写真との重なり・折返し事故を目視確認**してから commit
6. `get-export-formats` → `export-design` でPNG書き出し(ダウンロードURLをユーザーに渡す)

座標系の注意: read-design の `pos: A,B` は **A=top(y), B=left(x)**。テキストの font_size 変更時は幅が足りないと折返すので、先に resize_element で幅を確保する。

### パイプラインγ: AI写真×CSS紙面(最高品質・要API設定)

`scripts/gen-photo.sh` で料理写真を生成し(gpt-image-1)、HTML/CSSの紙面に `object-fit:cover` で組み込む。
写真の空き空間(湯気・暗部)に文字を置く。プロンプトの定石はスクリプト冒頭のコメントを読む。
前提条件: 環境のネットワーク許可(api.openai.com)+ OPENAI_API_KEY。未設定なら403で失敗するので
ユーザーに設定を依頼するか、ユーザーがチャットに貼った写真を使う(実店舗写真が最優先、次にAI生成)。

### パイプラインβ: HTML/CSS(写真が不要・図版中心のとき)

比較表・インフォグラフィック・文字中心の品書きなど。手順・テンプレート・フォント設定は `references/pipeline.md` を読むこと。書き出しは `scripts/render.mjs` を使う(車輪の再発明をしない)。

- 画面用: 4:3 (800×600) or 正方形 (800×800)、deviceScaleFactor 2
- 印刷用: A4 = 794×1123px(96dpi相当で組み、@2xで書き出し)。塗り足しが要る入稿は上下左右+12px
- 出力はRGB。実際の印刷入稿ではCMYK変換で彩度が落ちる(特に赤・緑)ことを施主に伝える

## 出荷前チェックリスト

- [ ] 型を1つ選び、混ぜていない
- [ ] 色は3+1色以内 / フォント2種以内
- [ ] 最大文字と本文の比が3倍以上ある
- [ ] 価格の数字が瞬時に読める(小さくて細い価格は事故)
- [ ] 揃え線が通っている(左端・ベースライン・価格の右端)
- [ ] 事務情報が最下部に1列で整列している
- [ ] 余白を「埋めたい衝動」に負けていない(特にD型)
- [ ] 架空の店・実績を実在のように見せていない(景表法・ステマ規制)

## 参照

- `references/patterns.md` — 4つの型の詳細設計規則(レイアウト・実例分析・お手本4点の解剖)
- `references/canva-observations.md` — Canvaテンプレートの構造実測値(フォントサイズ比・配色・落とし穴)と解剖手順。Canvaパイプラインを使う前に読むこと
- `references/pipeline.md` — アートボードの組み方・フォント・書き出し手順
- `scripts/render.mjs` — PNG書き出しスクリプト

新しいジャンルの案件を受けたら、`references/canva-observations.md` の解剖手順で類例をサンプリングして実測値を追記してから作ると精度が上がる(スキルは育てるもの)。
