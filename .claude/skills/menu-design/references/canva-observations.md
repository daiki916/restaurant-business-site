# Canvaテンプレート構造解剖 — 実測ノート

`generate-design` → `create-design-from-candidate` → `read-design`(transaction) で
プロテンプレート由来のデザインをCDF(座標・フォントサイズ・色・トラッキング)として抽出した実測値。
サンプルはCanvaフォルダ「デザイン研究(menu-designスキル用)」に保管。
新しいジャンルを扱うときは同じ手順でサンプルを増やし、このファイルに追記すること。

## 分析手順(再現レシピ)

1. 対象ジャンルの詳細ブリーフで `generate-design`(4候補返る)
2. 1案を `create-design-from-candidate` でデザイン化
3. `read-design` に `open_transaction: true` + fields `design_content`,`thumbnails` — 全要素の pos(top,left)・size・fontSize・color・letterSpacing・lineHeight・fontRef が出る
4. 数値を正規化して比較する: **フォントサイズはキャンバス高さに対する%で見る**(絶対値はサイズ依存で比較不能)
5. 編集不要なら transaction は放置でよい(期限切れで消える)

## 実測値(2026-07 時点、3サンプル)

### サンプルA: インパクト系(ラーメン新商品告知 / IG 1080×1350)— 優良例

| 要素 | 実測 | キャンバス高さ比 |
|---|---|---|
| 見出し「新登場」 | 148.9px 筆文字 赤#ff0000 tracking **-0.1** | **11.0%** |
| 商品名 | 52.0px 金#e1a84b | 3.8% |
| 価格 | 43.4px 金(商品名と同色) | 3.2% |
| 注記 | 15.6px 金 | 1.2% |

- 落差スパン 149→15.6 = **9.5倍**。見出し/商品名で2.9倍(スキルの「3倍」規則と一致)
- **筆文字の大見出しは負のトラッキング(-0.1)で塊にする** — 正のトラッキングだと迫力が死ぬ
- 配色は黒写真背景 + 赤 + 金の3色ちょうど。価格と商品名を同じアクセント色で束ねる
- 見出しと商品名の間に**筆ストローク画像を区切りとして挿入**(666×86の横長素材)
- 写真は「背景に湯気のフルブリード写真 + 前面に丼の写真」の2層。文字は湯気ゾーンに載せ、丼には掛けない

### サンプルB: 余白系(カフェランチ / A4横)— 失敗例として学ぶ

- 生成物はブリーフの**メニュー4品・価格・営業時間の大半を脱落**させ、「L.O. 14:00」だけを78px(高さ比9.8%)で巨大表示した
- **教訓: Canva生成物は必ず「掲載必須情報の完全性チェック」を通す。**文言が落ちていたら別候補を試すか、edit-designで補う
- 拾える数値もある: 英字小ラベル「WEEKLY LUNCH」は18.9pxで letterSpacing **0.3**(強トラッキング)。
  白地に単色アクセント#c89e6d(茶金)のみ = 余白系は「白+墨+アクセント1色」で成立
- セリフ見出しの下に細字トラッキング英字ラベルを重ねる2段ロックアップはテンプレート頻出パターン

### サンプルC: 上質系(居酒屋 秋宴会ポスター / 1587×2245)— 修正で完成させた例

- 生成直後: 見出し47.7px(高さ比2.1%)・価格40.6px・補足43px — **階層が平板でスキル規則に全違反**
- 修正後: 見出し90px(4.0%)太字・価格72px金太字・補足30px・注記22px → 商用品質に到達
- 配色は紺地 + 金#e2b95e + 白。写真は「串焼き大 + 紅葉小」の主従2枚、金の細罫フレームでレイヤー感
- **教訓: Canvaの弱点は一貫してタイポの落差不足。写真・配色・素材は信頼してよいが、文字階層は毎回このスキルで矯正する**

## 横断的に確認できた規則(暫定、サンプル3)

- 大見出しの目安: インパクト系は**キャンバス高さの10〜11%**、上質系・余白系は**4〜6%**
- 注記・事務情報は高さの**1.2〜1.5%**
- アクセント色は最大2色。価格は商品名と同じアクセント色に載せると視線が繋がる
- 英字ラベルは小さく+強トラッキング(0.2〜0.3)、日本語の迫力見出しは負トラッキング
- 区切りは罫線ではなく**素材画像**(筆ストローク・細罫フレーム)を使うと既製品らしさが出る

## 既知の制約

- 公開テンプレートライブラリの直接検索APIはない。`generate-design` 経由のサンプリングで代替する
- 候補のサムネイルはデザイン化するまで自分では見られない(design.canva.aiのURLはユーザーのみ閲覧可)
- 生成は文言を脱落させることがある(サンプルB)。完全性チェックを必須工程とする
